   fast-food finding as "here's who's responsible" — consistent with the source page's own

   project's public output.

   rebuilt the whole pipeline from scratch" is a plain fact, not a boast); both explicitly surface
   the parts that *didn't* replicate cleanly (MSS weakening, H3c non-revival) rather than
   cherry-picking the flattering half of the table — this is the single most important honesty
   check for a "re-check" post, since the temptation to only publish the confirmatory half is real

## Risks (non-blocking)

- The LinkedIn variant's compressed framing ("replicates cleanly ... swap in the official monitor
  ... signal weakens") could be skimmed as "thesis confirmed, then not confirmed" without reading
  the linked page's nuance (three separate panels, not a binary confirm/disconfirm). The caveat
  sentence partially mitigates this; recommend the maintainer's actual post text, if edited before
  posting, keep that caveat sentence intact rather than trimming it for length.

  H1 finding it produced is correctly restated. This is an acceptable compression for a short-form
  post (the full correction narrative lives on the linked page); not a factual gap in what *is*
  stated.
