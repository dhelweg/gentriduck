Social status & trajectory

This section shows the distribution of this Stadtteil's constituent Gebiete's own trajectory classifications — never a single re-scored index value for the Stadtteil itself, unless a future ticket promotes this grain to primary-equivalent scoring (currently out of scope; see docs/epic-i/I21-ia-restructure-scoping.md §2.2's headline row).

Two things to know before reading this section (#317):
1. Recent window, not full history. These labels describe a bounded ~6-year window (2019–2025) of Hamburg's own annual Sozialmonitoring panel, not the full 13-edition (2013–2025) series — the same cadence-normalized window already used for Berlin (H-C2, #159), applied here to Hamburg's annual cadence for the first time (#314). A Gebiet classified persistently-deprived or stable-established below reflects only the last ~6 years, not necessarily its full history — don't read it with the same long-run framing Berlin's own multi-decade biennial figures might imply.
2. Status-only, not a displacement verdict. stable-established, persistently-deprived, improving, declining, and mixed describe how each Gebiet's officially-measured social status moved over that window — never a claim about who moved, why, or whether any resident was displaced. See methodology for what this classification does and doesn't claim.

3 of 7 Gebiete here show a clear improving or declining trajectory over the 2019–2025 window; no single trajectory type holds a majority — a distribution across this Stadtteil's own Gebiete, never a single re-scored value for the Stadtteil itself.
